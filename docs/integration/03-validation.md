## 真实联调

四个基础服务 PostgreSQL、Redis、Neo4j、Milvus 均 ready。两个 API、两个页面及知识服务 Worker 均已运行。

smoke_live.py 的八项检查通过，详细结果写入本机 .runtime/smoke-live.json：

1. 知识服务账号为 viewer。
2. CarePilot 实际使用 MedKnowledgeHub 后端。
3. 医学知识问题得到带引用回答，保持原有问诊字段及待答问题。
4. 原文与回答来源版本一致，未登录的患者不能通过代理读取原文。
5. 科室推荐使用业务目录中的可预约科室。
6. 预约先产生 pending_confirmation，拒绝确认后 cancelled，不自动提交。
7. 第二患者账号不能读取第一患者会话。
8. 急症分支清除来源和建议，不新增知识问答记录。

页面测试使用 Streamlit AppTest 连接真实 API，完成发送问题、显示来源卡、点击读取原文，结果写入 .runtime/ui-smoke.json。它不是外部浏览器跨设备兼容性测试。

后台监督进程通过文件心跳提供状态，并接收 stop 请求；停止保留基础容器和所有持久数据。共享 Key 修改后应重启两个 API 和 Worker。
