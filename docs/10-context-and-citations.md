# 上下文工程、引用与来源差异

源码位于 `app/retrieval/context.py` 和 `app/agents/graph.py` 的 synthesize/verify。

## 上下文整理

候选先去除重复正文，再按相关度与来源等级整理。优先补充同一 Block 的父正文；每条保留独立 citation_id、文档版本、章节、页码和原文位置。上下文同时限制字符数与保守的 UTF-8 字节预算；该预算是 byte-BPE 下文本 Token 数的保守上界，不是 Qwen 精确分词统计，提示词和输出仍需额外余量。

父正文不能跨越权限范围，临近块不能在没有版本校验时任意拼接。当前实现以同 Block 父上下文为主，不承诺跨文档自动合并。

## 引用校验

模型返回的每条 claim 包含 text、source_ids、quotes。程序要求来源 ID 存在，且 quotes 中的文本逐字包含在对应上下文里；无效条目被移除。没有剩余有效条目时返回无法形成可靠回答的提示，不显示伪造引用。

这一检查证明“引文存在且来源绑定有效”，不能证明每条结论都被引文在语义上充分支持。Faithfulness 和临床正确性需要独立评测。RAGAS 评测入口在 `evals/ragas_eval.py`。

## 来源等级与冲突

authority 是由资料管理员核实的标签，不是系统自动认证的权威性。版本和有效日期先决定资料能否参与检索，排序时再考虑相关度与等级。当前冲突检查针对部分键值形式的不同表述，输出“可能差异”，不会自动裁定哪份临床指南正确。

## 原文读取与 SSE

页面可以展开引用，通过 `/sources/{chunk_id}` 读取父正文、页码和 bbox；原文接口同样执行知识库权限校验。SSE 先展示真实节点进度，完成引用校验后才逐段发送最终回答，避免把未经校验的模型草稿提前显示。

练习：将受控模型的引用 ID 改为不存在的值，运行 `test_rag.py`；再对比正常结果，说明引用 ID、引文存在和语义支持这三个概念。
